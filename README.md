# 🔥 Inferno Studio

Inferno Studio is an AI-powered **Neural Style Transfer** web application built using **AdaIN (Adaptive Instance Normalization)** and PyTorch.

Upload a content image and a style reference, adjust the style strength, and generate an artistic image by transferring the visual characteristics of the style image onto the content image.

## ✨ Features

- 🎨 Neural Style Transfer using AdaIN
- 🧠 PyTorch-based deep learning model
- 🖼️ Upload content and style images
- 🎚️ Adjustable style strength
- 🌐 Interactive web interface
- 💾 Download the generated stylized image
- 🔥 Modern fire-themed UI
